# BASHECO Godot client

Godot 4 project (checked with Godot 4.6-stable). Import once with
`godot --headless --path client --import`, run with `godot --path client`.

## One world

There is a single scene and a single coordinate system for the whole republic:
EPSG:32640 metres, 6 m cells, 64×64-cell chunks, one origin (`scripts/world_grid.gd`,
identical to `server/basheco/world_grid.py`). A settlement is a region of that world.
Choosing one in the geography menu moves the camera; no other map is loaded.

- `scripts/world.gd` — camera, input, plots. Global cells are integers; drawing is
  relative to `render_origin`, a chunk-aligned cell that follows the camera.
- `scripts/geo_background.gd` — atlas `data/world/`, chunk streaming (on-screen chunks
  plus one ring, at most 64, two loads per frame, far chunks are freed).
- `scripts/geo_chunk_node.gd` — one chunk drawn once in cell space; panning only
  moves node transforms. Level of detail depends on zoom.
- `data/world/` is generated by `python -m basheco.world_atlas` from
  `server/geodata/`. Do not edit it by hand: a server test rebuilds and compares it.

The map shows real OpenStreetMap geometry (© OpenStreetMap contributors, ODbL 1.0)
and SRTM contours. Coverage is partial: a small extract of central Ufa and the
village of Mikhailovka. Empty ground means "not imported yet". OSM buildings are
background only and never become playable plots.

Controls: drag with one finger or middle mouse button, pinch or mouse wheel to zoom,
tap or left click to select a plot. Zoom range 0.004–2.4.

## Server

Plots come from `GET /v1/world/viewport` in global world cells. The client refuses
plots if the server's grid version differs from its own. The token stays in memory;
non-local connections require HTTPS. Legacy settlement-local `tile_x/tile_y` are
never used to place anything.

## Tests

```sh
godot --headless --path client -s tests/grid_parity.gd      # client math == server pyproj
godot --headless --path client -s tests/smoke.gd            # world, streaming, travel, UI
godot --headless --path client -s tests/streaming_soak.gd   # memory and chunk release
python server/tests/e2e_world_client.py                     # real API + this client
```

Android: `godot --headless --path client --export-debug Android out.apk` (needs export
templates, Android SDK build-tools and a debug keystore). A debug-signed APK must not
be published as a release.
