# Kenney CC0 sprites in BASHECO

Downloaded on 2026-11-12 from the original author Kenney's OpenGameArt mirrors:

- `building_45.png`, `building_55.png`, `building_85.png`, `building_115.png`: `PNG/buildingTiles_045.png`, `055.png`, `085.png`, `115.png` from [Isometric Buildings #1](https://opengameart.org/content/isometric-buildings-1), archive `https://opengameart.org/sites/default/files/Isometric%20Buildings.zip`.
- `city_0.png`, `city_36.png`: `PNG/cityTiles_000.png`, `036.png` from [Isometric City](https://opengameart.org/content/isometric-city), archive `https://opengameart.org/sites/default/files/isometricCity.zip`.
- `detail_10.png`: `Details/cityDetails_010.png` from the same Isometric City archive.

Author: **Kenney** (https://kenney.nl/). License for both source packs: **Creative Commons Zero 1.0 (CC0)**. Commercial use, modification, and redistribution permitted; attribution optional. No other sprites in the source archives are included in this repository.

Modifications: renamed selected PNG files, runtime scaling and placement. Source PNG pixel data not edited.

Visual representation: generic building/tree illustrations, **not** real-world facade/height/tree inventory. OSM remains the source for building footprints, roads and mapped forest boundaries. Trees are placed as deterministic decorations within forest polygons. A rendering cap avoids unbounded sprite counts on Android.
