# Публичный API: контрольный список безопасности

Статус: **публичный тестовый HTTPS API включён 12 ноября 2026**. Docker API по-прежнему слушает только loopback VPS.

Перед включением публичного API обязательно:

1. Ограничить размер запросов, частоту регистрации/логина и финансовых операций в Nginx по реальному `$remote_addr`. Использовать отдельные зоны, не менять глобальные лимиты остальных сайтов.
2. Согласовать доверенную схему передачи клиентского IP от Nginx до FastAPI. Текущий `request.client.host` за reverse proxy будет адресом прокси, поэтому все клиенты попадут в одну корзину rate-limit. Нельзя без проверки доверять произвольному `X-Forwarded-For`.
3. Закрыть случайные маршруты, запретить CORS с произвольных origins, отключить debug/OpenAPI (уже отключено).
4. Добавить сквозные HTTP-тесты регистрации, входа, компаний, строительства, производства и покупки, включая ошибки, 429, idempotency и параллельные операции.
5. Спроектировать стартовую эмиссию валюты с ограничениями и аудитом. Сейчас игровые кошельки создаются с нулевым балансом; рынок нельзя считать пригодным для новых игроков.
6. Проверить восстановление Termalin backup в изолированном окружении и выполнить нагрузочный тест с отдельной БД.
7. Проверить APK на физическом Android и обновление клиента. Не использовать debug-подпись как релизную.

Публичное включение API допускается только после этих проверок и отдельного smoke-test HTTPS маршрута. До этого Godot поддерживает офлайн-карту и формы, но сетевые функции недоступны пользователям.


## Проверенный запуск 12 ноября 2026

- BASHECO-only Nginx rate limits: 15 запросов/с общие, 10 входов/мин, 2 регистрации/мин, с burst.
- Nginx передаёт IP с приватным секретом; FastAPI проверяет секрет и корректность IP, внешние заголовки не доверяются.
- 32 теста и отдельный сквозной HTTP-тест регистрации, входа, компании, строительства, производства, продажи и отмены прошли.
- Публичные HTTPS проверки: health JSON 200, неавторизованный рынок 401, невалидный запрос 422. Сайт и APK 200.
- Создан резервный архив Termalin, приватные значения не загружены в GitHub.

**Осталось:** нагрузочный тест, восстановление архива в изолированной среде, тест на физическом Android, защита от ботов, эмиссия стартовой валюты и удобная цепочка строительства в клиенте. Это ранний публичный тестовый API, не релиз MMO.
