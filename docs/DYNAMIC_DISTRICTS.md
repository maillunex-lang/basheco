# BASHECO: динамические кварталы v1

После успешного строительства в `ufa-prototype-01` сервер в той же транзакции резервирует блокировку сектора и генерирует до восьми соседних игровых участков 5×5 клеток в радиусе двух блоков по 8 клеток. Зоны назначаются детерминированно. Перед вставкой проверяются границы сектора и пересечение со всеми существующими участками. Максимум 2000 участков на сектор. `generated_by_growth` в миграции 008 отличает созданные участки от исходных. Существующие UUID компаний, участков и построек сохраняются.

Клиент Godot: раздел «Стройка», выбор свободного участка, POST `/v1/world/buildings`, отображение количества новых участков и повторная загрузка сектора. Рендеринг участков ограничен видимой областью. В текущем прототипе идентификатор компании вводится вручную; следующим шагом нужен удобный выбор компании и типовых зданий.

**Ограничения:** это игровые участки, не реальные кадастровые границы. Дороги и квартальная геометрия OSM автоматически не расширяются. Новые участки создаются только после строительства, не по времени и не из-за роста населения. Сектор сейчас возвращает весь список участков, поэтому для масштабирования нужен API с пагинацией/чанками, индекс пространственных координат и удаление из памяти невидимых объектов. Расширение размеров карты в сторону севера/запада ещё не поддержано. Стоимость строительства в тестовом секторе пока нулевая.
