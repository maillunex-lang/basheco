# Экономика BASHECO: первая вертикальная механика

Состояние: серверный прототип, **без публичного API и без настоящих денег**.

## Игровой цикл

1. Игрок создаёт компанию через `POST /v1/companies`.
2. Компания занимает подходящий свободный участок и строит теплицу либо мастерскую через `POST /v1/world/buildings`.
3. Клиент получает рецепты из `GET /v1/economy/catalog`.
4. Владелец запускает `POST /v1/economy/produce` с JSON `{"building_id":"UUID","recipe_code":"grow_vegetables","idempotency_key":"unique-request-123"}`.
5. Сервер блокирует компанию, проверяет собственность и назначение здания, ресурсы, паузу между циклами и ключ повторного запроса, затем атомарно списывает сырьё и начисляет продукцию.
6. Игрок видит склад через `GET /v1/economy/inventory`.

Все игровые запросы требуют заголовок `Authorization: Bearer <session>`. Публичный HTTPS-доступ к API ещё закрыт.

## Тестовые рецепты

| Здание | Рецепт | Вход | Выход | Пауза |
|---|---|---|---|---|
| Теплица | grow_vegetables | Нет | 10 овощей | 300 с |
| Мастерская | pack_food | 5 овощей | 3 упаковки продуктов | 120 с |
| Мастерская | make_parts | Нет | 1 запчасть | 600 с |

Рецепты **балансировочные заглушки**, не финальные экономические коэффициенты. Все количества целые. Никакого начисления валюты, платной покупки земли или открытой торговли ещё нет. Добыча без сырья временно ограничена паузой. При повторе того же ключа продукция повторно не начисляется; при смене параметров с тем же ключом сервер отвечает 409.

**Ограничения:** клиент Godot пока не имеет интерфейса производства; отсутствуют торговля, логистика, реальные кадастровые участки, исследования, стоимость строительства и добыча по физическим месторождениям. Реальные геоданные OSM используются исключительно как визуальный слой. Не выдавать тестовые участки за реальную собственность.

## Проверка

26 тестов в отдельной базе `basheco_integration_test` прошли 12 ноября 2026, включая одновременный запуск производства, повтор запроса, ограничения зон, собственность, бухгалтерию и ограничения частоты запросов. Перед миграцией `005_production.sql` создан архив Termalin. API остаётся на `127.0.0.1:4219`.

Следующие задачи: экран компании/склада/производства в Godot, серверные предложения обмена между компаниями с транзакционным расчётом, затем экономическая балансировка. Публичный API открывать только после дополнительного security-review.
