# BASHECO: торговля ресурсами (прототип)

Рынок работает только через защищённый серверный API на localhost VPS. Не является торговлей за реальные деньги.

## Операции

- `GET /v1/market/listings`: до 200 активных предложений, сортировка по времени.
- `POST /v1/market/listings`: JSON `{"company_id":"UUID","resource_code":"vegetables","quantity":10,"unit_price_kopecks":100}`. Склад продавца уменьшается, товар резервируется в предложении.
- `POST /v1/market/listings/{id}/buy`: JSON `{"company_id":"UUID","quantity":4,"idempotency_key":"unique-buy-123"}`. Атомарно списывает валюту покупателя, начисляет продавцу, передаёт ресурс, создаёт сбалансированные проводки.
- `POST /v1/market/listings/{id}/cancel`: только продавец возвращает непроданный резерв на свой склад.

Все маршруты требуют Bearer-токен. Сервер проверяет собственность компаний, целочисленные количества, ограничения цены и суммы, остаток денег и склада, предотвращает самопокупку. Запись покупки и две проводки выполняются в одной транзакции. Повтор покупки с тем же ключом возвращает исходный результат, изменение параметров с тем же ключом возвращает 409.

**Ограничения:** пока отсутствуют налоги, комиссии, доставка, рынок заявок, аукционы, денежная эмиссия и интерфейс торговли в Godot. Существующие кошельки игроков изначально имеют нулевой баланс. Для интеграционных тестов начальные балансы создаются **только в отдельной тестовой БД**. Торговые ограничения и балансировочные цены прототипные.

## Проверка 12 ноября 2026

Миграция `006_market.sql` применена на VPS после резервного копирования Termalin. В базе `basheco_integration_test` успешно завершены 30 тестов, включая конкурентную покупку, возврат резерва, проводки, повтор запроса, проверку собственности и недостаток средств. Публичный API не открывался.
