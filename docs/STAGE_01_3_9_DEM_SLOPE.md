# BASHECO, этап 1.3.9: автоматическая проверка рельефа по DEM

Дата: 2026-11-12. Изменения только в GitHub, без развёртывания на работающем сервере.

## Реализовано

`server/basheco/dem_source.py`: автономный адаптер локального DEM GeoTIFF. Работает в отдельной среде с rasterio/numpy. Требует проекцию с горизонтальными единицами в метрах, nodata и один канал высот; отклоняет географические градусные координаты и повёрнутые растры.

Для центра каждой занятой клетки игры вычисляется уклон по окрестности 3×3 **исходных пикселей DEM** методом Хорна. При уклоне выше демонстрационного порога 15° состояние `terrain=blocked`. При низком уклоне, отсутствии данных, выходе за границы растра или ошибках покрытия `terrain=unknown`. **Никогда не ставится `terrain=clear` по одному DEM**. 15° не является официальным нормативом строительства; он нужен для первичного игрового выявления крутых склонов и требует отдельного решения по типам объектов.

`geography_audit.py` принимает `--pilot-dem`, `--dem-source`, `--dem-version`; можно совместно использовать `--pilot-worldcover`. Источники проверяются только для пилотной Михайловки. Не создаёт разрешений на публикацию и не меняет базу данных.

## Проверено

В изолированном контейнере Python 3.13 + rasterio/numpy: 3 теста DEM (крутой склон, плоская поверхность, выход за растр, отказ от географического CRS) и 2 теста прежнего географического аудита. Все пройдены.

## Ещё не сделано

**Настоящий DEM-файл пока не получен и не проанализирован.** Нельзя утверждать, что склон Михайловки проверен на реальных высотах. Для этого нужен подтверждённый источник (например, доступный по лицензии Copernicus DEM GLO-30), проверка загрузки и контрольной суммы, вертикального датума, разрешения и точности. Затем отдельный анализ участка и отчёт. Не путать синтетические тесты с реальными геоданными.

Нужны дополнительные слои гидрографии, охраняемых территорий и прав на землю. Продакшен не затронут.
