## Безопасная эксплуатация

```sh
cd /opt/basheco
docker compose ps
docker compose logs --no-color --tail=50 api
docker compose logs --no-color --tail=50 db
curl -fsS http://127.0.0.1:4219/health
docker compose run --rm --no-deps api python -m unittest discover -s tests -v
```

Никогда не показывать содержимое `.env` в чате, логах или репозитории. Перед изменением существующего Nginx нужно создать копию его конфигурации, выполнить `nginx -t`, а затем отдельно проверить HTTPS и другие сайты.

## Что ещё не готово

- Нет публичного API, Android APK, Godot-клиента и запущенного игрового мира.
- Регистрация не должна быть доступна снаружи до внедрения rate limiting, защиты от автоматизированных регистраций, аудита, восстановления доступа и полноценного мониторинга.
- Стартовая эмиссия денег, казначейство, товары и производство ещё не реализованы; новые кошельки имеют нулевой баланс.
- Требуются тест восстановления из резервной копии, внешняя копия бэкапа и нагрузки.
- Нельзя считать этап 1 полностью завершённым до закрытия этих пунктов.
