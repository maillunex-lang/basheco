# Подэтап 1.2: географический справочник Башкортостана

Статус на 12.11.2026: **набор данных собран и проверен тестами; сверка с официальным файлом ОКТМО не выполнена.**
Клиент, база данных, API и VPS не затронуты. Данные лежат в `server/geodata/admin/`.

## Решения, действующие для этапа

- Слой реальных улиц и домов Уфы и Михайловки убирается на подэтапе 1.4, перед удалением состояние сохраняется в архивной ветке.
- Экспериментальная клеточная карта в разработке не используется.
- В справочнике только русские названия; другие языки не ведутся.

| Населённые пункты: название, тип, код ОКТМО, координаты, население | Wikidata: объекты внутри Q5710 с кодом ОКТМО (P764) | CC0 1.0 | 12.11.2026 |
| Официальный классификатор ОКТМО | Росстат | — | **не получен** |

Сайты Росстата, Башкортостанстата и Госсобрания РБ из среды сборки недоступны (обрыв соединения, ошибка 503); недоступны также Geofabrik и Overpass. Поэтому:

- перечень и коды взяты из Wikidata, куда они внесены участниками по данным Росстата, а не из самого классификатора;
- границы отражают состояние OSM на дату загрузки, а не официальный срез на 1 января 2026 года;
- число «54 района и 9 округов» совпало в OSM и подтверждается справочными публикациями, но по тексту закона РБ не сверено.

Эти оговорки записаны в `dataset_version.json` (блок `verification`). Сырые выгрузки в репозиторий не кладутся; в `sources.json` записаны адреса, время и контрольные суммы.

## Идентификаторы

- Формат: вид записи и код ОКТМО на момент первой выдачи: `R80000000`, `M80652000`, `S80701000001`.
- Выданный идентификатор не меняется никогда, даже если код ОКТМО позже изменится; реестр — `id_registry.json`.
- Соответствие старым текстовым идентификаторам (`legacy_ids.json`): `ufa` → `S80701000001`, `mikhailovka` → `S80652440101`. Старые идентификаторы в коде не менялись.

| `issues.json` | Журнал расхождений |

Границы хранятся как общие отрезки: соседние муниципалитеты ссылаются на один и тот же отрезок, поэтому после упрощения между ними нет щелей и наложений. Обзорный уровень — 10 092 точки (193 КБ), детальный — 20 051 точка (362 КБ), исходный — 54 604 точки.

У каждого пункта с координатами есть мировая клетка единой сетки `basheco-grid/1` — это будущая точка привязки игровой территории.

## Сборка

```sh
cd server
python -m basheco.geo_registry normalise RAW_DIR   # только при обновлении источников
python -m basheco.geo_registry build                # офлайн, детерминированно
python -m unittest tests.test_geo_registry
```
