# Подэтап 1.2: географический справочник Башкортостана

Статус на 12.11.2026: **справочник собран по ОКТМО и проверен тестами.** Версия набора `bashkortostan-admin/2026-01-01/r2`.
Клиент, база данных, API и VPS не затронуты. Данные лежат в `server/geodata/admin/`.

## Решения, действующие для этапа

- Слой реальных улиц и домов Уфы и Михайловки убирается на подэтапе 1.4, перед удалением состояние сохраняется в архивной ветке.
- Экспериментальная клеточная карта в разработке не используется.
- В справочнике только официальные русские названия; другие языки не ведутся.

Wikidata не добавляет и не переименовывает населённые пункты: она только даёт координаты и население к коду ОКТМО.

### Что проверено по файлу ОКТМО

- Формат совпадает с открытыми данными Росстата (13 столбцов, разделы 1 и 2, номер и даты изменений); в файле 186 533 строки, изменения утверждены до 02.06.2026.
- Регион найден по названию раздела: «Республика Башкортостан» встречается только под кодом территории 80.
- Контрольные цифры кодов верны во всех 6368 строках региона (вне региона не сошлись 75 строк из 186 533).
- Последнее изменение по региону: № 523, введено 01.02.2022.
- Все 4538 сельских населённых пунктов ОКАТО совпали с ОКТМО по району, типу и названию; остальные 23 записи ОКТМО — 21 город и 2 рабочих посёлка.

### Что не проверено

- **Файл получен с частного зеркала**, сайт Росстата из среды сборки недоступен; побайтно с файлом Росстата он не сверен. На странице зеркала указана дата актуализации 14.02.2026, хотя файл содержит более поздние изменения.
- **Реестр административно-территориальных единиц и населённых пунктов РБ** (постановление Правительства РБ от 29.12.2006 № 391) не использован: по карточке ГАРАНТ постановление опубликовано «без Реестра», публичного текста нет.
- Границы отражают OSM на дату загрузки, а не официальное описание границ.

Эти оговорки записаны в `dataset_version.json` (блок `verification`) и в `sources.json`. Сырые файлы в репозиторий не кладутся; записаны адреса, время и контрольные суммы SHA-256.

## Идентификаторы

- Формат: вид записи и код ОКТМО на момент первой выдачи: `R80000000`, `M80652000`, `S80701000001`.
- Выданный идентификатор не меняется и не удаляется. Идентификатор `S80622428111`, выданный в версии r1 по данным Wikidata, помечен `retired` и больше не используется.
- Соответствие старым текстовым идентификаторам (`legacy_ids.json`): `ufa` → `S80701000001`, `mikhailovka` → `S80652440101`.

Границы хранятся как общие отрезки, поэтому после упрощения между соседями нет щелей и наложений. У каждого пункта с координатами есть мировая клетка сетки `basheco-grid/1` — будущая точка привязки игровой территории.

## Сборка

```sh
cd server
python -m basheco.geo_registry normalise RAW_DIR   # только при обновлении источников
python -m basheco.geo_registry build                # офлайн, детерминированно
python -m unittest tests.test_geo_registry
```

`RAW_DIR` содержит `oktmo.csv`, `okato.csv`, выгрузки OSM и Wikidata и `download_log.json`.

## Проверки

- `python -m unittest tests.test_geo_registry`: 19 тестов пройдено.
- Все серверные тесты на одноразовой базе PostgreSQL 16: 123 пройдено, 0 провалено.
- Проверяется: состав, названия и типы равны ОКТМО; совпадение с ОКАТО; 54 + 9 и 818 + 14; уникальность идентификаторов; отсутствие дублей внутри поселения; согласие координат с границами и мировой сеткой; отсутствие щелей на обоих уровнях; год и ссылка у населения; побайтная воспроизводимость сборки; неизменность выданных идентификаторов.
