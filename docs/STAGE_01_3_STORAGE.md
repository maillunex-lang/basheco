# Этап 1.3.3: безопасное хранение генерируемых локаций

Статус: **код добавлен, автономные тесты пройдены, миграция на рабочем VPS НЕ применялась**.

## Добавлено

- `server/sql/016_generated_locations.sql`: отдельные таблицы `generated_locations` и `generated_location_chunks`. Новые записи по умолчанию **не опубликованы**. Существующие участки игроков, объекты, деньги и владение не меняются.
- `server/basheco/generated_storage.py`: валидация с лимитом 5 пунктов на муниципалитет, контролем повторов и пересечений сгенерированных клеток, детерминированным SHA256 и разбиением по чанкам 64×64. `import_unpublished(bundle)` по умолчанию работает **только в dry-run**, без базы. Для записи нужен явный `dry_run=False`; импорт неизменяемый и повторяемый, не перезаписывает опубликованное.
- `server/basheco/api.py`: авторизованные read-only маршруты `GET /v1/world/generated/locations` и `GET /v1/world/generated/{settlement_id}/chunks/{chunk_x}/{chunk_y}`. Они возвращают только опубликованные записи. Пока никто не опубликован в новых таблицах, результат пуст.
- `server/tests/test_generated_storage.py`: пять тестов без БД, все пройдены.

## Важные ограничения

Это **не завершённая MMO-система генерации**. Пока отсутствуют: проверка конфликтов с реальными участками/строениями игроков перед публикацией, согласованный административный процесс публикации, синхронизация списка клиента с API, интеграционный тест PostgreSQL и тест APK. Сохранённый в клиенте пилот Михайловки остаётся прежним.

Не включать публикацию или импорт в живую базу, пока не реализована транзакционная проверка конфликтов с `world_plots` и `world_object_cells` и пока не получены результаты интеграционных тестов. На сервере работающие контейнеры и база не изменялись.

## Проверки

На изолированной копии: `PYTHONPATH=server python3 -m unittest discover -s server/tests -p test_generated_storage.py -v`: **5/5 OK**. `python3 -m compileall -q server/basheco/api.py`: успешно. Зависимости `psycopg` нет в системном Python VPS, поэтому полноценная DB/API-интеграция не запускалась.
