# Этап №1: единая карта Башкортостана

Статус: **в работе, не завершён**. Выполняем только карту, без изменений строительства, экономики и VPS.

## Сделано в GitHub
- Общая метрическая сетка `server/basheco/world_grid.py`: EPSG:32640, клетка 6 м, чанк 64×64, один мировой якорь (0,0).
- `server/basheco/world_projection.py`: точное преобразование WGS84 (lon,lat) в EPSG:32640 через pyproj, далее в глобальные клетки и чанки.
- `server/tests/test_world_projection.py`: обратное преобразование и отрицательные/общие координаты.
- `server/requirements.txt`: pyproj.

## Текущее ограничение
- `client/scripts/geo_background.gd` всё ещё принимает локальные equirectangular-данные и применяет разные `origin_tile`. Нельзя переключать этот клиент на новую сетку без предварительной конвертации геоданных.
- `world_plots` и `world_sectors` всё ещё хранят старые локальные индексы с ограничением 4096. Нельзя интерпретировать их как глобальные клетки.
- Имеющиеся OSM-чанки содержат локальные метры. Их нужно пересоздать в глобальном CRS из исходных координат, сохранив provenance, границы и идентификаторы объектов.
- Проверка round-trip двух координат выполнена локально; полный набор репозиторных тестов и Godot не запускались.

## Следующие задачи строго в рамках этапа №1
1. Проверить исходные OSM-данные, генераторы и форматы манифестов для Уфы и Михайловки; зафиксировать контрольные точки.
2. Реализовать версионированный экспорт OSM в общую EPSG:32640 без придуманной геометрии.
3. Перевести Godot на глобальные координаты с камерой относительно ближайшего чанка для предотвращения потери точности.
4. Разделить локальные координаты старых участков и глобальные координаты мира, написать безопасный план миграции и проверки совпадения.
5. Проверить бесшовный переход между населёнными пунктами, загрузку чанков, FPS и память Android; запускать сервер только с отдельного разрешения.

## Критерий готовности этапа
Одна и та же реальная точка имеет одинаковый глобальный адрес в сервере и клиенте; Уфа и Михайловка располагаются на правильном расстоянии, без отдельных карт и фиктивных кварталов. Переход камеры не теряет объекты, а старые данные не повреждаются.
