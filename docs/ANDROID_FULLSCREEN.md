# Android: широкий экран и полноэкранный режим

12 ноября 2026: для телефонов с широким экраном (включая iQOO 15R) включены `display/window/stretch/aspect=expand`, `canvas_items`, горизонтальная ориентация и `immersive_mode=true`. Это устраняет ограничение игрового viewport соотношением 16:9; игровое поле должно расширяться по горизонтали, а не добавлять чёрные полосы.

Собран новый debug APK; автоматический Godot smoke test прошёл, подпись APK проверена, файл доступен по прежнему адресу.

**Требуется проверка на устройстве:** реальный размер окна, системные жесты и вырез камеры, safe area для интерфейса, работа сенсорных панелей на широком экране. Если полосы остаются, проверить Android «Полноэкранное отображение приложений» и скриншот с устройства. Эмуляция и автоматические тесты не заменяют физический iQOO 15R.
