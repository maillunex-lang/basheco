# Этап 1.3.1: пилот процедурной локации и фильтрация списка

Дата: 12.11.2026. Этап 1.2 принят пользователем после проверки Android APK.

## Сделано

- Полный справочник ОКТМО остаётся в `client/data/admin_navigation.json` (63 муниципалитета, 4561 населённый пункт). Ничего из официальных данных не удаляется.
- **Игровой список** показывает только населённые пункты, у которых есть опубликованная генерированная локация с домами и подтверждёнными координатами. Пустые районы, сёла и города скрыты из поиска и списка; они появятся по мере публикации построек. Сейчас только Михайловка Уфимского района.
- `tools/generate_pilot_location.py` воспроизводимо создаёт `client/data/generated_locations.json`: Михайловка, 62 клетки дороги и 15 схематичных жилых домов с площадями 1×1, 1×2 и 2×2 клетки. Сетка единая, 6×6 м, координаты берутся из официального каталога. Поле `residents_hint` — **черновая оценка**, не реальные жители или экономика.
- `world.gd` показывает пилотные дороги и дома отдельным графическим слоем поверх существующей географии. Это визуальный прототип, **не серверные участки**, не собственность игроков, не записи в базе и не система строительства.
- Переключение и поиск ограничены доступными локациями; прямой вызов выбора скрытой локации в меню тоже ничего не делает.

## Тестирование

Godot 4.6 Stable, изолированная рабочая копия:
```sh
python3 tools/generate_pilot_location.py
godot --headless --path client --editor --quit
godot --headless --path client -s tests/stage13_pilot.gd
godot --headless --path client -s tests/navigation.gd
godot --headless --path client -s tests/smoke.gd
godot --headless --path client -s tests/grid_parity.gd
godot --headless --path client -s tests/streaming_soak.gd
```
`BASHECO_STAGE13_PILOT_OK available=1 houses=15 roads=62`; остальные перечисленные проверки прошли.
