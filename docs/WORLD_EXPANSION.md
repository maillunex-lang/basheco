# BASHECO · расширяемый мир

## Реализовано

- Стартовая карта сектора `ufa-prototype-01`: **200×200** клеток. Миграция `007_expand_world.sql` меняет размеры сектора без удаления или изменения существующих `world_plots` и `world_buildings`.
- Godot вычисляет границы видимой области через обратную изометрическую проекцию и рисует только видимые клетки. Не создаются 40 000 отдельных нод.
- После успешного строительства вблизи правой/нижней границы сектора сервер атомарно увеличивает размер соответствующей оси с запасом 64 клетки. Максимум 4096×4096. Сервер авторитетен, клиент читает размеры из `/v1/world/sectors/ufa-prototype-01`.
- Имеющиеся шесть тестовых участков остаются прежними. Новые земельные участки не создаются автоматически, поэтому на данном этапе расширение при строительстве у границы недостижимо через обычный интерфейс. Это **механизм готовности к росту**, а не законченная система градостроительства.
- OSM-пилот остаётся ограничен исходным снимком центра Уфы. Новая площадь карты не означает наличие геоданных на все 200×200 клеток.

## Следующий этап

Создать серверное размещение игровых участков в допустимых свободных зонах, проверку перекрытий и прав, генерацию кварталов по спросу, чанковую загрузку участков вместо ответа со всеми объектами, отображение доступных границ и динамическое расширение геоданных. При расширении на север/запад потребуется модель координат со смещением, не только увеличение `width_tiles` и `height_tiles`.
