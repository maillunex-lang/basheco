# BASHECO · географическая архитектура v1

## Слои и независимые идентификаторы

1. **Административный каталог**: Республика Башкортостан → муниципальный район / городской округ → населённый пункт → район города → географический фрагмент. Идентификаторы административных единиц отделены от OSM way/node IDs.
2. **Географический слой**: датированные OSM-снимки, дороги и контуры зданий в WGS84, фрагменты по bbox; каждая запись содержит источник, дату и атрибуцию © OpenStreetMap contributors, ODbL 1.0.
3. **Игровая проекция**: преобразование долготы/широты в локальные метры (поправка cos широты), затем в изометрию. При смене масштаба отрисовываются только видимые фрагменты.
4. **Экономика**: `world_sectors.id`, `world_plots.id`, `world_buildings.id`, `companies.id` остаются неизменными. OSM-объекты не являются юридическими земельными участками. Старый `ufa-prototype-01` сохраняется для совместимости с существующими записями и тестами.
5. **Сервис данных**: отдельный будущий read-only endpoint каталога и чанков, с проверкой bbox, ETag и кэшированием; экономика не зависит от сетевого сервиса OSM. Нельзя обращаться к публичному OSM API на каждый кадр/пользовательский запрос.

## Вертикальный срез

Первый район: центральная часть Уфы, первоначальный маленький снимок OSM, далее расширение на один реальный городской район после проверки геоданных и лицензии. Используется **локальное разбиение по фрагментам**, без запроса к OSM в Android. Снимки имеют версии и могут обновляться независимо от экономики.

Клиент показывает **реальные контуры улиц и зданий** отдельно от шести **синтетических тестовых участков**. Нельзя обозначать синтетические участки как реальные кадастровые.

## Этапы расширения

- Версия 1: формат и разбиение OSM на локальные чанки, географическая проекция, отсечение невидимых чанков, видимая атрибуция, тесты Godot и Android.
- Версия 2: серверный каталог районов и поселений с стабильными ID, выбор региона, кешируемая загрузка чанков.
- Версия 3: один район Уфы целиком, LOD и поиск, сопоставление игровых зон с географией.
- Версия 4: другие районы Уфы, населённые пункты и республика; отдельный источник официальных границ при необходимости.

## Правовые и технические ограничения

OSM © OpenStreetMap contributors, ODbL 1.0: https://www.openstreetmap.org/copyright. Фиксировать дату и URL исходного снимка. Отображать атрибуцию в приложении. OSM не даёт прав собственности и не заменяет кадастровые данные. Не копировать защищённые коммерческие карты. Большие территории загружать по фрагментам с LOD и лимитами памяти. Отдельные реальные границы и административные названия должны проверяться, не выдумываться.

## Реализовано в первой итерации (12.11.2026)

- Офлайн-манифест `client/data/ufa_chunks/manifest.json` и 16 JSON-фрагментов, созданных из уже проверенного снимка OSM центральной части Уфы. Пересекающиеся фрагменты могут ссылаться на один OSM way; отрисовка убирает дубликаты по `osm_id`.
- `client/scripts/osm_overlay.gd` читает манифест, лениво загружает видимые чанки, кэширует их в памяти, отсеивает невидимые и использует локальную проекцию с поправкой на широту. На карте выводится атрибуция.
- Существующие шесть тестовых участков и API `ufa-prototype-01` оставлены без миграции и изменений. Данные OSM не используются для определения собственности.
- Godot headless smoke пройден, Android debug APK экспортирован и проверен по подписи. Реальное устройство пока не проверено.

**Ограничение:** 16 фрагментов покрывают только исходный маленький снимок центра Уфы, а не весь административный район. Следующий шаг: получить более широкий законно доступный OSM extract, построить версионированные чанки, ограничить память LRU-кэшем, сделать каталог административных районов и отдельные координатные якоря игровых секторов.
