# BASHECO: большой мир, следующий инкремент (2026-11-12)

## Реализовано
- Клиент Godot загружает до двух географических чанков за кадр, удаляет далёкие, сохраняет исходные OSM ID и источники. Чтение FileAccess синхронное и ограничено бюджетом чанков, это **не** отдельный поток ввода-вывода.
- Серверная функция `sector_viewport(sector_id, min_x, min_y, max_x, max_y)` и HTTP `GET /v1/world/sectors/{sector_id}/viewport`. Возвращаются только участки, пересекающие запрошенный прямоугольник, с информацией о владельце и предприятии. Размер запроса не более 512×512 клеток, максимум 2000 участков в одном ответе. Запрос не меняет состояние БД и не создаёт участки.
- Офлайн-конвертер `python -m basheco.import_osm_xml` преобразует OSM XML way-объекты в JSON чанки 256×256 метров, включая здания, дороги, лес, воду и поля, с атрибуцией ODbL. Отдельный источник и дата загрузки обязательны. Нет автоматических запросов к публичному OSM API.
- 47 серверных тестов после сборки Docker-образа в изолированной тестовой БД прошли успешно.

## Ещё не реализовано
- Массовый импорт **всей** Уфы и Михайловки. Нужен лицензированный полный OSM extract, обработка multipolygon relations, проверка границ, геометрическое отсечение объектов на чанки и ограничения размера ассетов. Текущие OSM данные всё ещё пилотные.
- Интеграция viewport API в Godot клиент. Пока сервер умеет отдавать область, но клиент продолжает запрашивать целый прототипный сектор.
- Полноценное создание серверных игровых участков за пределами прототипа с пространственными проверками, экономическими транзакциями, правами доступа и антиколлизиями.
- Асинхронный I/O в отдельном потоке, приоритет загрузки, LOD на масштабе всего города.
- Проверка FPS/памяти/управления на физическом Android устройстве. Headless smoke не является таким тестом.

## Безопасность
- Существующие реальные OSM здания только визуальный фон. Серверные игровые участки имеют отдельные идентификаторы и права.
- Для тестов использована только БД `basheco_integration_test`. Продуктивная БД не мигрировалась, сервисы не перезапускались.
- Существующие сайты и приложения на Lunex не затрагивались.
