# BASHECO Alpha UI: интерфейс и навигация

## Принципы
- Android landscape 1280×720, адаптивные отступы и крупные зоны касания; интерфейс только на русском.
- Тёмная графитовая основа `#101c28`, поверхности `#142634` и `#203844`, бирюзовый акцент `#28616a`, светлый текст `#e5edf1`. Не перекрывать игровую карту несколькими панелями одновременно.
- Игровой мир и OSM не рисуются за экраном авторизации. Камера при старте направлена на центральную часть **игрового квартала** (локальные клетки 12,12), а не на геометрический центр всей карты 200×200. Это место первого игрового района, не центр географической Уфы.
- Отрисовка сетки ограничена видимым прямоугольником с запасом; участки за экраном не рисуются. OSM использует существующие локальные чанки. При масштабировании нельзя подгружать сразу всю республику.

## Экранная структура
1. **Вход**: BASHECO, имя (для регистрации), email, пароль, войти, зарегистрироваться, посмотреть демонстрационную карту. Технический адрес API скрыт, используется настроенный HTTPS.
2. **Город**: основной игровой экран, компактная информация о выбранном участке, карта с панорамированием и масштабом, единая нижняя навигация.
3. **Компания**: создание и выбор компании, капитал, предприятия, склад (последние три ещё требуют отдельных UI-блоков).
4. **Стройка**: выбранный участок, компания, тип допустимого здания, подтверждение и обновление квартала.
5. **Производство**: предприятия, рецепты, сырьё, запасы, запуск и завершение.
6. **Рынок**: лоты, выбор компании, продажа и покупка, подтверждение сделки.
7. **Настройки**: графика, звук, аккаунт и выход (запланировано).

## Выполнено в первой итерации
Полноэкранный фон авторизации, центрирование формы, скрытие карты до входа/деморежима, стартовая камера на квартале, ограничение рендера видимой областью, унификация тёмных панелей и нижней навигации. Оставшиеся пункты являются проектным планом, не реализованными функциями.

## Следующая итерация
- Отдельная адаптивная верхняя HUD-панель с данными сервера (компания, игровой баланс, район), без ложных значений.
- Плавный pinch zoom вокруг точки жеста, ограничения камеры, кнопка «К центру района».
- Полноценные экраны компании, производства и рынка без UUID; настройки и безопасный выход.
- Раздельная подгрузка кварталов/участков по координатным чанкам с сервера, профилирование Android и реальные тесты нескольких экранов.
