# BASHECO: этап 1.2 — административная навигация

Статус на 12.11.2026: **код реализован и проверен на чистой копии GitHub main с Godot 4.8.beta3; реальное Android-устройство не проверено**. Развёртывания игры на VPS не было.

## Область этапа

Только интерфейс навигации по административному справочнику и перенос камеры на единой карте. Генератор локаций, экономика, здания, схема БД и действующие контейнеры не менялись.

## Источник истины

- `server/geodata/admin/`: версия `bashkortostan-admin/2026-01-01/r2`, ОКТМО (файл с зеркала, не побайтно сверенный с Росстатом), OSM и Wikidata. Подробности: `docs/STAGE_01_2_GEO_REGISTRY.md`.
- `tools/export_navigation.py`: детерминированный экспорт из 63 файлов муниципалитетов в `client/data/admin_navigation.json`. Сгенерированный файл хранится в GitHub и автоматически обновляется workflow `.github/workflows/navigation-catalog.yml`.
- `client/scripts/geography_menu.gd`: экран «Республика → 63 района и городских округа → населённый пункт», поиск по всей республике, поиск внутри района, 60 записей на страницу, пояснение муниципалитета, типа и сельсовета, ОКТМО в подписи.
- `client/scripts/world.gd`: `open_world_cell` центрирует ту же общую карту по официальной мировой клетке, запоминает название для интерфейса, кнопка фокуса возвращает к выбранной точке.
- `client/scripts/geo_background.gd`: область перемещения камеры расширена по подтверждённым координатам всех населённых пунктов. Старый OSM-атлас Уфы и Михайловки не ограничивает общереспубликанскую навигацию.

## Правила и ограничения

- 4 561 населённый пункт в каталоге, все 63 муниципалитета присутствуют.
- 4 538 населённых пунктов имеют координаты со статусом `inside_municipality`; только у них активна кнопка перехода.
- У 23 пунктов местоположение недостоверно или отсутствует (7 без пригодных координат, 16 за пределами указанного муниципалитета): записи остаются видимыми, переход отключён.
- Одноимённые пункты различаются типом, районом, сельсоветом и кодом ОКТМО. В справочнике найдено 27 населённых пунктов с названием «Михайловка».
- Переход не создаёт новой сцены города и не подменяет систему координат.
- **За пределами ранее импортированных фрагментов Уфы и Михайловки на карте пока нет подробных дорог и домов.** Это не ошибка навигации; наполнение локаций относится к следующему этапу.
- Код ОКТМО по-прежнему основан на зеркале официального классификатора. Невыясненные ошибки координат отмечены в `server/geodata/admin/issues.json`.

## Что требуется до формального закрытия

1. Запустить игру на реальном Android-устройстве: поиск названий, ввод с клавиатуры, скролл 60 пунктов, длинные названия, возвращение в меню, одноимённые пункты, масштаб и удержание выбранной локации.
2. Проверить сборку на целевой стабильной версии Godot 4.6 (на Lunex для теста использовался 4.8.beta3).
3. Проверить Android-экспорт и доступность JSON-каталога внутри APK; на Lunex экспорт не прошёл из-за отсутствующих шаблонов для Godot 4.8.beta3, настроек debug keystore, Java SDK и platform-tools. Это ограничение тестовой машины, не доказательство дефекта проекта.
4. После успешного приёмочного теста зафиксировать закрытие этапа и только затем перейти к этапу 1.3 «Генератор локаций».
