# BASHECO: пилот реальной географии Уфы и Михайловки

## Реализовано

- В одном Godot-мире можно открыть Уфу (игровой квартал) и Михайловку (только просмотр) через меню Республика → муниципалитет → населённый пункт. Для переключения не создаётся новая сцена; игровые участки Уфы сохраняются, в Михайловке строительство заблокировано отсутствием игровых участков.
- OSM-геометрия хранится отдельно от игровых участков. Дороги, реальные контуры зданий, водоёмы и леса не создают право собственности. Контуры зданий не заливаются непрозрачным серым цветом.
- Координаты OSM переводятся из WGS84 в локальные метры с сохранением источника, исходной даты и лицензии. Это локальная аппроксимация для пилотных фрагментов, не окончательная CRS для всего Башкортостана.
- Реальные высоты из SRTM30m, полученные через OpenTopoData, отображаются изолиниями с шагом 10 м. Источник, дата получения и высоты сохранены в JSON; пропущенные высоты не генерируются.
- Сельская карта содержит реальную дорожную сеть, контуры зданий, один лесной контур и два водных объекта по OSM, **только в пределах ограниченного извлечения**. Карта не является полной моделью населённого пункта.
- Исходные полигоны на краю извлечения обрезаются геометрически, чтобы исключить прежние гигантские непрозрачные фигуры. Отрисовка геометрии кэшируется и отсеивается по видимой области камеры.

## Фактические источники

- Уфа: OpenStreetMap API, bbox `55.971,54.7377,55.973,54.7395`, исходный снимок 2026-11-12, атрибуция © OpenStreetMap contributors, ODbL 1.0. Файл `client/data/ufa_projected_pilot.json`.
- Михайловка, Уфимский район: OpenStreetMap relation `2552635`, координаты центра `55.8916795,54.8050459`. Геометрия из OSM API, bbox `55.881,54.797,55.904,54.814`, атрибуция © OpenStreetMap contributors, ODbL 1.0. Восемь файлов в `client/data/mikhailovka_wide/`.
- Высоты: `https://api.opentopodata.org/v1/srtm30m`, SRTM30m. Для Уфы сетка 8×8, для Михайловки 10×10, файлы `client/data/*_elevation_pilot.json`. Это разреженные высотные выборки, а не точная 3D-поверхность. Диапазон выборки Уфы 173–181 м, Михайловки 83–159 м.
- Официальная статистика населения пока **не загружена**. Серверная схема требует год, источник, дату получения и охват. Экономика NPC пока **не запущена**. Не подменять её реальными деньгами граждан.

## Ограничения, которые необходимо устранить до полного этапа

1. Уфа: загрузить и обработать реальную границу города и все фрагменты, а не маленький центр. Разделить подгрузку геоданных по экрану на асинхронные чанки.
2. Село: подготовить полную границу и лесные/водные объекты в пределах реальной локации, а не прямоугольника пилота.
3. Исправить соотнесение географических координат и игровых участков: сейчас метрическая география отображается поверх условной игровой сетки с пилотным масштабом 4 м/клетка (Уфа) и 6 м/клетка (Михайловка). Это **не точное пространственное совмещение**.
4. Усовершенствовать рельеф (сетка высот/меш, затенение), деревья и стилизованные модели зданий. Пока показаны контуры и изолинии, не готовый красивый город.
5. Сервер: API чанков, кэширование, обновления между игроками, экономические показатели и NPC. Нужны профилирование на Android и тесты с двумя реальными аккаунтами.

## Воспроизведение

- `PYTHONPATH=server python3 -m basheco.osm_snapshot input.osm mikhailovka output.json`
- `PYTHONPATH=server python3 -m basheco.elevation_snapshot mikhailovka WEST SOUTH EAST NORTH 10 output.json`
- `godot --headless --path client --editor --quit`
- `godot --headless --path client --script res://tests/smoke.gd`

**Безопасность:** источники не предоставляют кадастровых прав. Публичные API не следует массово опрашивать из Android; сбор выполняется офлайн с соблюдением лимитов и условий использования.
